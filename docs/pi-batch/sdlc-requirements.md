Spec written to `docs/requirements/2026-08-06-message-recall-time-window.req.md` (v2, as-built). Since the feature was implemented and gated in the prior round, this spec is a **verification-led document**: every requirement is anchored to the shipped code, not a plan.

**Key verified facts**:

- **Config**: `AERO_RECALL_WINDOW_SECS` plain env (`.env.example:149`), default 86400, `0`=unlimited, invalid→86400 silent fallback (`parse_recall_window`, `service/messages.rs:45`); read once at `ImService::new` with a boot log (`orig.rs:316`); additive `with_recall_window` builder.
- **Boundary (inclusive)**: single shared predicate `recall_window_expired` in `aero-common` (`model/message.rs:31`) — `age <= window` allowed; `t=window` proven at the **unit** level with one captured clock (`messages.rs:769`), storage tests use latency-proof margins (86399s→Ok / 86401s→Err) because `now_fence − created_at = 86400s + ε` makes the exact instant unprovable against a real clock.
- **Transaction fence**: `recall_outboxed_authorized(id, actor, window, …)` evaluates on the `FOR UPDATE`-locked snapshot (`authorization.rs:262-269`), author-only via `sender_id == actor` (admin/owner exempt), appended **last** after deleted/recalled/role so precedence and the member-no-leak property hold (pinned by two leak tests).
- **Migration impact: none, verified** — `migrations/` = 238 before and after; the recall UPDATE needs **no new WHERE predicate** (row lock already makes the app-level check atomic; the SQL alternative duplicates role logic and mixes DB/app clocks — rejected with evidence); existing fence unchanged.
- **Compatibility**: 409/`conflict` envelope untouched; the wire `msg` carries the thiserror prefix (`"conflict: recall window expired"`) — pinned by the server contract test (`error.rs:68`) and the real-envelope web test; window-expired is *not* in the "409-as-success" mapping, surfaced as an info toast via `web/recall_errors.js`.
- **Acceptance**: all criteria green — unit parse+boundary, 6 storage integration tests (admin override, margins, zero-window, race partition, precedence, no-leak), 4 service tests, contract test, 5 web tests; gates: check/clippy clean, `cargo test --workspace --lib` ~1100 green, web-check 0 violations, truth-check 0 orphans, `test-integration.sh` 605/605, `node --test web/` 127/127, plus the fixture-hermeticity regression (suite green with `AERO_RECALL_WINDOW_SECS=1` exported).
