## 1. Scope

Land the unimplemented core of B5-1: **L1 window aggregation for the high-volume message backlog lane**, so the relay stops being moderation-only.

- **In scope**: 0242 trigger + function (single, merged — never two); leaf vocabulary pins (allowlist consts, window key derivation); `is_admin_class` doc re-point; AC1/AC2/AC3 db_tests + drill extensions; AC4 harness slot swap + 0242 file gate; parity drill.
- **Out of scope (sibling owns)**: production-path audit writers (`insert_outboxed` / `edit_outboxed_authorized` append `message.create`/`message.edit` rows), room.* lane aggregation (low volume, pass-through), 0239/0240/0241/0236 edits, connector changes (proven unnecessary, E5/E10).
- **Merge rule (arbitration)**: exactly ONE 0242 migration, ONE trigger function name (`aero_enqueue_l1_aggregate_audit`), ONE reconciler (none needed for message lane — unconditional trigger ⇒ no disabled-window gap ⇒ no 0241-style backfill; do not build one). The 0242 file gate (`test-integration.sh`) + parity drill are the double-count arbiters. Fixed allocation: 0242 is the last free number after 0241; a second slice landing a different 0242 first wins the number and this slice folds into it — never two files.

### 2.3 Migration 0242 — `migrations/0242_audit_governance_l1_aggregate.sql` (new, additive)

`CREATE OR REPLACE FUNCTION aero_enqueue_l1_aggregate_audit()` — AFTER INSERT ON `audit_events` FOR EACH ROW, parallel to 0236/0239 (firing order alphabetical: `aero_enqueue_governance_audit` < `aero_enqueue_l1_aggregate_audit` < `audit_events_snaplink_delivery`; none modified):

1. **Allowlist gate** (fail-open pass-through): `IF NEW.action NOT IN ('message.create','message.edit') THEN RETURN NEW; END IF;` — admin/room/unknown rows never touched (admin isolation).
2. **Window key** (deterministic, replay-stable): `v_key := NEW.workspace_id::text || '|' || 'message' || '|' || floor(extract(epoch FROM NEW.created_at)/60)::bigint; v_event_id := md5(v_key)::uuid;` — `created_at` is server-stamped in `AuditRepo::append_on`, single clock domain.
3. **Merge** (primary path): `INSERT (event_id, status, class, priority, payload) VALUES (v_event_id, 0, 'message', 10, jsonb_build_object('event_id', v_event_id::text, 'source_system', 'aero-im.source' /* AUDIT_SOURCE_SYSTEM */, 'window_start'/'window_end' (from L1_WINDOW_SECONDS), 'first_event_at'/'last_event_at', NEW.created_at, 'count', 1, 'aggregated', true, 'action', 'message.batch' /* AGGREGATED_MESSAGE_ACTION */, 'idempotency_key', v_event_id::text …)) ON CONFLICT (event_id) DO UPDATE SET payload = audit_governance_outbox.payload || jsonb_build_object('count', (payload->>'count')::int + 1, 'last_event_at', NEW.created_at) WHERE audit_governance_outbox.status = 0` — **`status = 0` restored** (sibling R3/D5 + adversarial finding 1: `claim_due` snapshots payload at claim, so merging into a claimed (status=1) row rewrites the frozen in-flight snapshot — silent sink undercount on the delivery-success path, invisible to every in-repo parity; `IN (0,1)` is a regression). `ROW_COUNT = 0` ⇔ conflict-with-WHERE-false → uniform spill for status 1/2/3 (no DELETE path on the table makes the equivalence exact). Row lock on the PK serializes concurrent writers; under READ COMMITTED the loser's SET/WHERE re-evaluate on the winner's committed row (EPQ) — the guarantee is **READ COMMITTED-only**, see F5.
4. **Spill path** (merge no-op'd — `ROW_COUNT = 0` covers status 1/2/3 uniformly): `INSERT … VALUES (md5(v_key || '|' || NEW.id::text)::uuid, 0, 'message', 10, jsonb_build_object('event_id', spill_key::text, 'source_system', 'aero-im.source' /* AUDIT_SOURCE_SYSTEM */, 'window_start'/'window_end' of the late event's window, 'first_event_at'/'last_event_at', NEW.created_at, 'count', 1, 'spill', true, 'aggregated', true, 'action', 'message.batch', 'idempotency_key', spill_key::text …)) ON CONFLICT (event_id) DO NOTHING` — at most one row per late event, replay-idempotent, **settles normally** (own `event_id` + own key; fixes sibling F1/F4). **`spill: true` is the parity-drill discriminator** (the drill's SUM side selects `aggregated = true OR spill = true`) — a marker-less spill is invisible to the drill and reds.
5. **No runtime gate** (unconditional — mirrors sibling D2: no disabled-window gap, no message-lane reconciler). **No binding lookup** (unlike 0239 Gate 2 — L1 has no binding; keeps trigger body minimal).
6. `CREATE TRIGGER audit_events_l1_aggregate AFTER INSERT ON audit_events FOR EACH ROW EXECUTE FUNCTION aero_enqueue_l1_aggregate_audit();`
7. Header pins: `DEFAULT 10` = `GOVERNANCE_PRIORITY_BACKLOG` (governance.rs:33); class `'message'` = `GOVERNANCE_CLASS_MESSAGE`; allowlist/action/source literals = leaf consts §2.1; search_path pinned (`SET search_path = pg_catalog, public` — canonical spelling of sibling security finding F5).

### 2.4 Storage db_tests — `crates/aero-storage/src/audit_governance.rs` (AC2, AC3-runtime pin)

New `#[ignore = "requires live Postgres"]` + `DATABASE_URL`-gated tests. **Every literal is derived from the leaf consts — never inline** (G2 closure: truth-check scans `crates --glob '*.rs'` only, so the 0242 SQL side is unpoliced; the db_test IS the SQL pin):

  - Rollback half → 0 outbox rows (trigger writes are in-tx with the audit rows); second window (`created_at − 2*$L1_WINDOW_SECONDS`) → second row; second workspace → third row.
  - 0242 presence probe: `to_regprocedure('aero_enqueue_l1_aggregate_audit()')` null → `eprintln!("SKIP: 0242 not migrated")` + early return (drill exit-2 precedent; the harness leg is 0242-file-gated anyway, so this only fires on a partially-migrated shared DB).

- **`l1_window_aggregates_concurrent_merge_serializes`** (F5 pin — the only artifact exercising the EvalPlanQual path directly; same harness leg): two parallel txs, same workspace + same window, each inserts one `$LOCAL_ACTION_MESSAGE_CREATE` audit row; a `tokio::sync::Barrier` after `BEGIN` (before the INSERT) makes both triggers race the same window-row PK — the loser blocks on the winner's row lock, then re-evaluates SET/WHERE on the winner's committed row. Assert: exactly 1 outbox row, `count = 2`, `status = 0`. Test-doc pins:
  - **READ COMMITTED-only guarantee**: the re-evaluation is a READ COMMITTED behavior; a pool move to REPEATABLE READ/SERIALIZABLE turns the second commit into 40001 → this test goes red loudly (isolation-change alarm), and in production the *message* tx would abort (availability, F5).   - **Dedicated pool**: the shared `pool()` helper caps at 2 connections — this test opens its own pool (`max_connections(3)`) and acquires 2 connections upfront so the txs can never deadlock the pool.

- **`admin_rows_never_merged_into_l1_window`** (AC3 runtime pin; runs under the existing `audit_governance::` harness leg): N `message.create` rows build a window row (count=N); then `moderate_finalize` → `message.moderated` yields exactly 1 admin 1:1 row (`event_id` = audit id, class 'admin', priority 100) **and the window row untouched** (count still N, no second row, no increment); then raw `message.moderated`/`message.deleted`/`room.create`/`auth.login` audit inserts → zero window rows created or incremented (token allowlist pass-through).

### 2.5 Drills + harness (AC1/AC4)

- `aero-audit-relay-drill.rs` — **the delivery-leg artifact** (restores the sibling's dropped A3 mixed-shape leg — this is the ONLY artifact that exercises the receipt path for window/spill shapes: T-11 never delivers (closed token endpoint), the parity drill's spill leg asserts payload fields but never delivers through the connector). Seed split of `rows` (`AERO_AUDIT_DRILL_ROWS`): `rows/3` 1:1-shaped + `rows/3` window-shaped (md5 PK, full arbitrated envelope, `count` 5) + `rows/3` spill-shaped (own deterministic key, `spill true`, `count` 1) — **every conforming payload carries `event_id` == own PK and `source_system` == config value** — plus **2 negative controls seeded with `attempts = 1`** (their first claim is attempt 2 → dead in-batch, no sleep): ① mismatched `payload.event_id` → dies at `ReceiptMismatch`; ② wrong `source_system` → dies at `PayloadGuard`. Assert (existing shape preserved, constants shift): `COUNT(status=2) == rows`, delivered `event_id` set == seeded conforming set (existing parity), `COUNT(status=3) == 2`, `COUNT(status IN (0,1)) == 0`, `stub.posts() == rows + 2`; optionally `seen_idempotency_keys()` == seeded ids in `AuditId` Display (pins the base32 header spelling for md5 PKs). **Why this proves settle**: status=2 is reachable only through POST → stub echo of `payload.event_id` → `receipt_event_id_matches` vs row PK → `settle` — any missing/mismatched `event_id`/`source_system` on any shape → permanent → dead → the status-2 parity goes red.
- `aero-audit-t11-drill.rs`: extend the seed with **window- and spill-shaped rows** (deterministic md5 event_ids, class 'message', priority 10, payload with `count`, `aggregated: true`, own `idempotency_key` + own `event_id`). **The extension seeds MUST carry `source_system`** (the 1:1 seeds already do) — `validate_delivery_payload` runs before any transport, so a guard-failing window row would dead (permanent) and break the `terminal == 0` invariant. **Assertion shapes are preserved — only the constants shift** (rows → rows+1: the drill's invariants are written in terms of the seeded count, so the extra window row shifts every constant, not the equations): `claimed == rows+1` per round, `pending == rows+1`, `terminal == 0`, `SUM(attempts) == (rows+1)*round`, `transport_errors == rows+1`; plus per-round keyed window-row evidence — `status = 0`, `attempts == round`, payload `count` intact, `last_error` = transport. A seed that silently drops the window row fails the shifted totals (non-vacuous). (T-11 seeds the outbox directly — it tests the relay on a row *shape*, not the trigger; trigger presence is the parity drill's job.)
- New `aero-audit-l1-parity-drill.rs` (AC4 arbiter; **T-11 self-seed precedent — seeds its input through the trigger, never direct outbox INSERT**):
  1. Self-isolating start (T-11 TRUNCATE-at-start guard): TRUNCATE `audit_governance_outbox` + DELETE the drill's own `audit_events` rows (scoped to the drill workspace); fixture workspace insert.
  2. **Self-seed through 0242**: capture one fixed `created_at` (`SELECT now()` once), `INSERT` N≥1 (`AERO_AUDIT_DRILL_ROWS`, default 5) `message.create` rows into `audit_events` with that timestamp → the trigger fires per row → exactly 1 window row, `count = N`. **Non-vacuity: N ≥ 1 ⇒ `COUNT(mapped) ≥ 1`, so a dropped trigger yields `SUM = 0 ≠ COUNT = N` → red** (a query-only drill would pass `0 == 0` with the trigger dropped).
  3. **Parity query — ALL message-class rows, window + spill**: `SUM((payload->>'count')::int) FROM audit_governance_outbox WHERE class = 'message' AND ((payload->>'aggregated') = 'true' OR (payload->>'spill') = 'true')` == `COUNT(audit_events WHERE action IN ($LOCAL_ACTION_MESSAGE_CREATE, $LOCAL_ACTION_MESSAGE_EDIT) AND window_start(created_at) >= cutoff)` — the **`spill: true` marker is load-bearing** (a marker-less spill is invisible to the SUM side → red), and the allowlist/class/window are **const-bound** on both sides (G2 applies to the drill too).
  4. **Retention scope — window-start on BOTH sides** (F7): per side, `window_start = floor(extract(epoch FROM created_at)/60)*60` — audit side from `audit_events.created_at`, outbox side from `payload->>'window_start'` — and `cutoff = now − AERO__SERVER__AUDIT_RETENTION_DAYS` (default 365, matching `boot/retention.rs`; `sweep_before` deletes `created_at < cutoff`, legal-hold-exempt). Scoping the audit side by `created_at ≥ cutoff` alone false-reds on straddling windows (surviving rows whose window_start < cutoff sit on the audit side but not the SUM side); window-start on both sides excludes them consistently. On the throwaway drill DB every window is fresh — the predicates are no-ops but must be present (correct on shared/long-lived DBs, same posture as 0241).
  5. **Spill leg**: `UPDATE` the window row `SET status = 2`; `INSERT` one more `message.create` row **with the same fixed `created_at`** (same window — a different window would create a new window row, not a spill) → exactly 1 spill row: `spill = 'true'`, `count = 1`, `event_id = md5(v_key || '|' || NEW.id::text)::uuid` (recomputed), `idempotency_key` = own event_id, `payload->>'event_id'` = own event_id (settle contract). ## 4. Failure modes

| # | Mode | Behavior | Detection / mitigation |
|---|---|---|---|
| F1 | 0242 not migrated / trigger dropped | Silent pass-through — zero window rows, zero errors | **Parity drill** (AC4) is **self-seeded through the trigger** (N≥1 `message.create` audit rows ⇒ `COUNT(mapped) ≥ 1`): dropped trigger ⇒ `SUM = 0 < COUNT` → red — never a vacuous `0 == 0`; 0242 file gate self-skips in harness (explicit SKIP verdict, never silent green) |
| F2 | Trigger-body error (e.g. count cast) | Aborts the audit INSERT + whole message tx (fail-closed, matches 0239 Gate 2 precedent) | Sole-writer assumption (F6) makes cast safe; db_test covers merge arithmetic; documented blast radius: message send/edit tx now aborts on outbox failure — keep body sub-query-free |
| F3 | Late event after window row claimed/delivered/dead (status 1/2/3) | `DO UPDATE … WHERE status = 0` affects 0 rows → `ROW_COUNT = 0` → spill row (own key, own `event_id`/`idempotency_key`/`source_system`, count 1, `spill`+`aggregated` markers) — never silent undercount, never rewrite of in-flight/terminal rows (settle's fenced re-read stays valid) | Parity drill; relay-drill delivery leg (spill shape settles, status=2); spill key deterministic per (window,event) → replay idempotent |
| F4 | Sink absent (T-11 shape) | Window rows pile up status 0/1; merges continue; O(windows) rows — the bounded property AC2 asserts | AC1 drill: window row never falsely dead, attempts monotonic |
| F5 | Concurrent writers, same window | PK row lock serializes merges; loser re-evaluates SET/WHERE on the winner's committed row — **guarantee is READ COMMITTED-only** (REPEATABLE READ/SERIALIZABLE ⇒ 40001 ⇒ fail-closed *message-tx* abort, availability); trigger lock-wait bounded by `statement_timeout = 10s` (db.rs:31) — a long batch tx on a hot window can push concurrent sends past it | `l1_window_aggregates_concurrent_merge_serializes` (two parallel txs, barrier, count=2 — the only EPQ-path artifact; goes red loudly if the isolation level ever changes) + AC2 sequential leg |
| F6 | Sibling collision on 0242/trigger name | Two files/definitions → migrate conflict, double-count | Single merged trigger rule (§1); fixed-allocation number guard; parity drill arbitrates; build→migrate order (§5) |
| F7 | Retention sweep of `audit_events` | Parity diverges for swept windows (outbox never swept — v1-parity, sibling R8) | Parity drill scopes **both sides by window-start** (`floor(epoch(created_at)/60)*60 ≥ cutoff`, `cutoff = now − AERO__SERVER__AUDIT_RETENTION_DAYS` default 365) — straddling windows excluded on both sides; audit-side `created_at ≥ cutoff` scoping alone would false-red |
| F8 | md5 collision across (workspace,class,window) | Wrong merge | 128-bit digest space (birthday bound ~N²/2¹²⁹ — 2²⁰ workspaces × 2²⁰ windows ≈ 2⁻⁴⁹); deterministic key; negligible; documented |
| F9 | Replay of an audit INSERT (at-least-once) | audit_events PK conflict aborts replay tx (app-layer concern, unchanged); trigger merge per row is idempotent | Existing semantics; no trigger change |
| F10 | `search_path` hijack | Trigger resolves wrong objects | `SET search_path = pg_catalog, public` in function (canonical spelling of sibling F5 closure) |
| F11 | Window/spill payload missing or mismatching `event_id` / `source_system` | Echo `"missing"` → `ReceiptMismatch`, or guard bail → `PayloadGuard` — both permanent → **dead after ≤1 retry, never delivered**; invisible to T-11 (never delivers) and to a query-only parity drill | F15 closure: `event_id` = own PK + `source_system` = `AUDIT_SOURCE_SYSTEM` pinned in §2.1/§2.3; AC2 asserts both + absence of forbidden keys; **relay-drill delivery leg with negative controls** is the detector (status-2 parity red on any missing pin) |
