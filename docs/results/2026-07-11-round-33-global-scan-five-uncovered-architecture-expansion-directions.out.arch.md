### 关键架构决策

- **方向五（审计）**：推荐 **Builder 模式** `AdminAudit::new().target_type(...).emit(&pool)`，而不是简单函数或多参数函数——调用一致性比代码行数更重要
- **方向一（客服嵌入）**：推荐**双层架构**（安全 iframe + JS SDK API 桥），复用 `rooms` 表并增加 `room_type='support'`，而不是新建独立消息表
- **方向二（Undo Send）**：推荐**立即持久化 + `undo_until` 列**方案，而不是 Redis 延迟持久化——数据不可丢
- **方向三（白标）**：推荐**反代层处理 TLS**（nginx/caddy），不自建 ACME，减少运维复杂度
